# Ароматека

Готовый сайт находится в корне проекта. Единственная главная страница — `index.html`, единственная страница ошибки — `404.html`.

- `pages/` — внутренние страницы.
- `Stylesheets/` — стили, включая адаптивную версию.
- `javascripts/` — формы, меню и анимации.
- `images/`, `fonts/` — локальные изображения и шрифты.

## Запуск

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:5173/ в любом браузере на этом компьютере. Страницы и анимации также можно открыть двойным кликом по `index.html`: скрипты подключены обычными файлами с `defer`. Для проверки отправки форм и обработки неизвестных адресов используйте HTTP-сервер.

## Проверка

```sh
npm run build
```

Команда проверяет синтаксис JavaScript и CSS, подключения файлов и ссылки между страницами. Копии HTML не создаются.

## Публикация

Загрузите на статический хостинг `index.html`, `404.html` и папки `pages`, `Stylesheets`, `javascripts`, `images`, `fonts`, сохраняя структуру. Файлы уже готовы для HTTP-сервера, отдельная папка сборки не требуется. `node_modules`, `.git`, `scripts` и конфигурация Vite для публикации не нужны.

На хостинге настройте выдачу `404.html` для неизвестных адресов. В режиме разработки это делает Vite.

Формы отправляют заявки в Formspree; подключение находится в `javascripts/newsletter.js`, адрес приёма — в HTML-формах.

## JavaScript

Скрипты подключены в HTML через `defer`: они запускаются после загрузки разметки.

- `shared.js` — хедер и кнопка «Назад».
- `mobile-menu.js` — мобильное меню с круговым открытием.
- `home.js` — вкладки манифеста и слайдер рубрик.
- `aroma.js` — вкладки страницы аромата.
- `newsletter.js` — проверка email и отправка формы.
- `placeholder.js` — появление букв, лепестки и розовая заливка на страницах в разработке.

В каждом файле отдельная функция-обёртка, чтобы одинаковые имена переменных не мешали другим скриптам.

Своего бэкенда, API и базы данных у сайта нет. Формы отправляются прямо в Formspree — это внешний сервис обработки заявок. Vite запускает локальный сервер для разработки и показывает 404 для неизвестных страниц.
