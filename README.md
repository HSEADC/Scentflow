# Ароматека

Статический multi-page сайт, который собирается Vite. Главная страница находится в `index.html`, страница ошибки — в `404.html`, остальные страницы — в `pages/`.

- `pages/` — внутренние HTML-страницы.
- `Stylesheets/` — исходные стили; Vite обрабатывает их через PostCSS.
- `javascripts/` — ES-модули с формами, меню и анимациями.
- `images/`, `fonts/` — локальные изображения и шрифты.
- `dist/` — production-сборка; создаётся автоматически и не хранится в Git.

React, ReactDOM, React-плагин Vite и Airtable пока не используются интерфейсом, но остаются установленными для следующих этапов проекта.

## Разработка

```sh
npm ci
npm run dev
```

Vite откроет локальный сервер на http://127.0.0.1:5173/. Он обрабатывает все HTML-страницы как точки входа и показывает `404.html` для неизвестных адресов.

## Проверка и сборка

```sh
npm run check
npm run build
npm run preview
```

- `check` проверяет локальные ссылки и синтаксис CSS.
- `build` сначала выполняет проверку, затем создаёт production-сборку в `dist/`.
- `preview` запускает локальный сервер из готовой папки `dist/`.

Все браузерные скрипты подключены как ES-модули через `type="module"`, поэтому Vite включает их в граф сборки, проверяет и объединяет общие зависимости.

## Публикация

Workflow `.github/workflows/deploy.yml` запускается после push в `main`, выполняет `npm ci` и `npm run build`, затем публикует папку `dist/` в GitHub Pages.

Для project pages используется базовый путь `/Scentflow/`, переданный через `VITE_BASE`. Локально базовый путь по умолчанию равен `/`.

## JavaScript

- `shared.js` — хедер и кнопка «Назад».
- `mobile-menu.js` — мобильное меню с круговым открытием.
- `home.js` — вкладки манифеста и слайдер рубрик.
- `aroma.js` — вкладки страницы аромата.
- `newsletter.js` — проверка email и отправка формы.
- `placeholder.js` — появление букв, лепестки и розовая заливка на страницах в разработке.

Своего бэкенда и базы данных у сайта пока нет. Формы отправляются напрямую в Formspree. Airtable оставлен как зависимость для будущей интеграции с данными.
